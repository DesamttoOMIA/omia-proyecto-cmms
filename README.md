# omia-proyecto-cmms

Sistema de gestión de mantenimiento (CMMS) de OMIA.

## Estado

Proyecto en fase inicial. El stack y la estructura de la aplicación aún están
por definir.

## Flujo de trabajo

- `dev` es la rama de integración y la rama por defecto. Todo PR de trabajo
  apunta a `dev`.
- `main` es producción. Solo recibe PRs de `dev` y únicamente el owner puede
  promoverlos.
- Cada PR requiere al menos una revisión del otro colaborador.

Ver [CONTRIBUTING.md](CONTRIBUTING.md) para el detalle de ramas, commits,
revisión y merges.

## Seguridad

No publiques vulnerabilidades en issues. Consulta [SECURITY.md](SECURITY.md).
