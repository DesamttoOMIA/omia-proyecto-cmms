# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público para reportar vulnerabilidades. Usa
[GitHub Security Advisories](../../security/advisories/new) o escribe a
**desarrollos.mtto@omia.com.co**.

Incluye:

- Descripción del problema y su impacto.
- Pasos para reproducirlo.
- Versión o commit afectado.
- Mitigación sugerida, si la tienes.

## Alcance

Este repositorio y sus despliegues asociados. Quedan fuera de alcance los
servicios de terceros.

## Compromiso

Confirmaremos la recepción, investigaremos y coordinaremos la divulgación
responsable antes de hacer pública la información.
